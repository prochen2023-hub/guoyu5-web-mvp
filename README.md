# 字字探險隊 V4.0｜南一五上國語

V4.0 在 V3.0 的 12 課完整生字／新詞與注音基礎上，加入「月考模擬考場」與閱讀分層。

## V4.0 新增
- 期中 A、B 卷（第 1～6 課）
- 期末 A、B 卷（第 7～12 課）
- 每卷 100 分：字音字形 40、詞語理解 20、閱讀理解 20、造詞造句 20
- 30 題客觀題自動批改；造詞造句使用參考答案與檢核表自評
- 45 分鐘可選擇開始／暫停的倒數計時
- 模擬卷列印模式
- 成績拆解成字音字形、詞語理解、閱讀理解、表達運用四項能力
- 答錯客觀題自動進「錯題回收站」，保留在 localStorage
- 四份卷採固定種子選題，每一卷內容穩定且 A/B 不同
- 每課閱讀理解由 3 題升級為 5 題，並標示「找答案／找證據／推論／主旨／詞句理解／篇章結構／修辭理解」等題型
- 首頁與期中／期末範圍卡直接提供 A／B 卷入口

## 既有功能
- 12 課、216 個生字，全部顯示注音與代表詞
- 約 185 組課內新詞與生字延伸詞
- 逐句跟讀、造詞造句、分層閱讀、6 字短目標手寫
- 手機手寫防頁面上下滑動
- PWA、localStorage、GitHub Pages branch deploy

## 內容說明
課名、生字、新詞依公開課程資料核對；導讀、延伸跟讀、閱讀題與模擬試題為本站重新設計，不重製出版社課文全文。
