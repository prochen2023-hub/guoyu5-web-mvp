# 字字探險隊｜南一五上國語 V5.0

本版針對 V4.0 全站互動失效做完整修復。根因是 `app.js` 綁定不存在的 `#wordsDoneBtn`，造成 JavaScript 在啟動中途停止，連帶讓手寫、救援字與模擬考功能未初始化。

## V5.0 修復
- 補回 `wordsDoneBtn`，並將靜態事件綁定改成防呆寫法，單一元件缺失不再拖垮全站。
- 今日跟讀任務直接開第 5 課「跟讀」，閱讀偵探直接開第 6 課「閱讀測驗」，不再兩個都落到導讀頁。
- 手寫 5 字救援、首頁「今天要救回的字」恢復可點；救援字增加注音與課次。
- 期中／期末 A、B 四卷恢復完整渲染；題本整張卡可點、支援鍵盤 Enter/Space。
- hash 路由支援 `lesson-5-read`、`lesson-6-quiz`、`exam-midterm-A` 等深連結，重新整理後仍回到正確關卡。
- 學習角色 🦊 改為「我的成就」入口。

## 內容升級
- 保留 12 課、216 生字、完整注音、本課新詞、延伸詞、造詞造句與 5 題分層閱讀。
- 每課新增 3 組「延伸成語」：共 36 組，含解釋、例句與朗讀；課程導覽會直接顯示成語數。
- 關卡名稱改為「字詞・成語」與「造詞造句・成語」，不把成語藏在頁面深處。
- 造詞造句頁新增「成語運用」練習，要求孩子把成語放進自己的情境句。
- 延伸成語為本站依課程主題整理，不宣稱為南一出版社固定課內成語表。
